28px type disc for search results and mention lists — people get initials on green-50, other entities a lucide glyph on their type tint (team green, project blue, story purple, class dark, assignment amber, task gray).

```jsx
<EntityIcon type="person" name="Ashton Liu" />
<EntityIcon type="task" />
<EntityIcon type="project" size="sm" />
```

In the codebase use lucide-react: `users`, `folder-kanban`, `check-square`, `bookmark`, `message-square`, `graduation-cap`, `clipboard-list`, `arrow-right`.
