Dashboard metric card (uppercase label, 2rem value, tinted icon chip) — mirrors DashboardMetricCard.

```jsx
<StatCard label="TSRs submitted" value="24/31" hint="7 outstanding" accent="primary" icon={<ClipboardCheck size={16} />} />
```

Accents: `primary` (green) · `blue` · `purple` · `amber`. Pass `onClick` to make it clickable.
