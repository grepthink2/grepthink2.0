Token-themed chart wrappers (SVG stand-ins for the app's recharts; use `CHART_COLORS` for recharts fills in production).

```jsx
<PieChartCard data={[{name:'Submitted',value:24},{name:'Missing',value:7}]} />
<BarChartCard data={[{name:'T1',value:4},{name:'T2',value:5},{name:'T3',value:3}]} />
```

Palette starts green `#018156`, then blue `#2771FF`.
